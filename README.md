# 小启 IT 助手 · 可运行交互 Demo

这是根据《智能 IT 工单助手 V1.0 PRD》制作的零依赖前端 Demo。重点不是覆盖所有后台能力，而是用真实可点击的交互演示一条完整业务闭环：

> 自然语言提问 → 必要信息澄清 → 企业知识排障 → 解决结果确认 → 自动整理工单 → 用户确认 → 模拟 ITop 创建 → 工单状态查询

## 运行方式

需要 Python 3。截图识别还需要 macOS 与 Xcode Command Line Tools（`swiftc`），无需 API Key 或第三方 Python 包。

```bash
cd it-assistant-demo
python3 server.py
```

浏览器打开：<http://localhost:4174>。首次启动会编译本地 OCR 程序，看到 `本地 OCR: True` 后即可上传截图。

从 GitHub 下载源码并解压后，在终端进入项目文件夹运行上述命令。若使用 Git 克隆，进入克隆得到的 `it-assistant-demo` 文件夹即可。

直接双击 `index.html` 或使用普通静态服务器仍能使用文字 Demo；上传识别须同时运行上面的 4174 服务。推荐固定用 4174 地址，避免浏览器对本地文件请求的限制。非 macOS 环境仍可运行文字流程，截图识别会明确提示不可用。

### 截图演示

1. 点击首页或聊天输入框左下方浅灰「＋」，选择 PNG、JPEG、WebP 截图（单张最大 5MB，单次会话最多 4 张）；也支持在输入框粘贴截图。
2. 预览后可移除；点击发送，可只发图，也可附加文字。
3. 本机 Apple Vision 实际识别截图中的中英文文字；规则提取错误码、系统及问题类型，不依赖文件名。
4. VPN / 网络问题进入现有排障流程；截图已包含系统时不重复询问。信息不足时仅请求补充，识别失败可重试或转人工。
5. 转人工时，截图、识别文字及真实反馈记录进入可编辑的模拟工单；「我的工单」详情可查看截图。

截图能力是 **本地机器学习 OCR + 规则分类，不是多模态大模型**，不能可靠解释没有文字的视觉故障，也不会宣称从截图确定根因。支持检测 VPN、网络、软件、权限及安全相关文字；超出现有知识的类别提供补充描述 / 转人工入口。企业知识与 ITop 仍为模拟。

截图仅发送到本机 `127.0.0.1` 服务，识别进程不保存原图；缩略图和识别结果保存在浏览器本地，会随模拟工单保留。请上传前遮挡敏感信息：文字脱敏不能清除原截图中的秘密。浏览器容量不足时会提示当前内容无法持久保存。

## 推荐演示路径

### 路径 A：完整排障并转人工（最完整）

1. 点击「VPN 认证失败」；
2. 选择 Windows 或 macOS；
3. 操作后直接点击「仍未解决」，进入下一条可靠排障方案；
4. 第二次操作后仍点击「仍未解决」，进入人工协同；
5. 选择紧急程度；
6. 查看 AI 自动生成的结构化工单，可点击「修改」；
7. 点击「确认提交」；
8. 点击「查看最新进度」，体验 ITop 状态查询。
9. 点击侧栏「我的工单」，查看编号、标题、状态和更新时间；点击任一工单查看详情、排障记录和处理进度。

工单列表初始为空，不预置虚假历史记录。新建会话会保留已创建的工单，刷新页面后仍可查看；右上角「重置 Demo」经确认后清除会话及工单。不同打开方式（本地 HTML、localhost、127.0.0.1）的浏览器存储相互独立，建议固定使用同一个地址演示。

### 路径 B：AI 自助解决

1. 点击「连不上公司网络」；
2. 选择系统并完成排障步骤；
3. 操作后直接点击「已解决」，立即结束服务，无需再次确认；
4. 查看自助解决闭环和满意度收集。

### 路径 C：能力边界转人工

1. 点击「申请办公软件」；
2. AI 识别该请求涉及授权与审批，不会虚构自动开通能力；
3. 点击「生成申请工单」，完成确认和提交。

还可以输入「我的工单处理到哪了？」体验自然语言查询；输入包含「密码」「Token」的文字，体验敏感信息提醒。

## Demo 已实现

- 不要求先选分类的自然语言入口；
- 单轮只追问一个关键环境信息；
- 模拟企业知识来源、相关指南及更新时间；
- 两轮状态驱动的故障排查，不重复失败步骤；
- 排障卡片直接提供「已解决 / 仍未解决」，一次反馈即决定后续流程；也支持输入同义结果；
- 主动转人工、排障失败转人工、能力边界转人工；
- 从对话自动提取问题、环境、排障过程和紧急程度；
- 工单提交前可编辑和确认；
- 模拟幂等提交 loading、ITop 工单号及状态时间线；
- 「我的工单」支持空状态、多条工单列表、详情与进度刷新；新建会话保留工单，在新会话查询多条工单时提供选择入口；
- 会话通过 `localStorage` 保留，刷新后可继续；
- 敏感信息提醒、非 IT 问题引导；
- 「＋」截图上传、预览与移除，本地 OCR、错误信息提取、失败重试，以及工单截图留存；
- 响应式布局、键盘发送、可见焦点、减少动画偏好支持。
- 界面采用低饱和蓝白配色、纯色背景和细边框，无阴影、无渐变，页面与卡片间距保持紧凑。

## 技术实现

- 原生 HTML + CSS + JavaScript；
- 无 npm、无构建步骤、无网络依赖；
- 用有限状态机式的前端逻辑模拟 Agent Loop；
- 用 `localStorage` 模拟会话和工单关联存储；
- ITop、知识检索、统一登录均为前端模拟数据，不会调用真实企业系统。

## 与真实产品的差异

此 Demo 用于快速验证交互和业务闭环，以下能力在真实产品中需要服务端实现：

- 企业统一身份认证与权限透传；
- LLM 问题理解、动作决策与多轮上下文；
- 企业知识向量检索、权限过滤及引用追溯；
- ITop 创建 / 查询 API、幂等和超时补偿；
- 服务端会话存储、审计、脱敏与数据埋点。

## AI 使用过程简述

本 Demo 采用 vibe coding 方式完成：

1. AI 先阅读完整 PRD，抽取 P0 核心闭环、关键异常路径和 V1 能力边界；
2. 使用 UI/UX 设计知识生成适合企业 AI 助手的界面方向：AI-native、低干扰、可信、对话优先；
3. 由 AI 生成页面结构、视觉样式和状态机交互代码；
4. 由 AI 进行语法检查、浏览器实机点击验证和响应式检查；
5. 人工可继续根据演示反馈调整话术、知识步骤及 ITop 字段映射。
6. 新增截图入口：AI 实现本地 OCR、异常恢复和工单截图留存，以合成 VPN 报错截图验证错误码、环境识别与多轮闭环。识别使用 [Apple Vision VNRecognizeTextRequest](https://developer.apple.com/documentation/vision/vnrecognizetextrequest)。

所有“企业知识”和 ITop 返回值均为演示用模拟数据，避免被误认为真实公司规则。

## 验证

`python3 -m unittest test_server.py` 验证分类、错误码、环境、空图兜底与明显秘密字段脱敏。`node --check app.js && node --check screenshots.js` 检查前端语法。真实 OCR 及界面闭环另通过本机浏览器上传合成报错图验证。
